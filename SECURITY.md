# Security Policy

## Supported Versions

This repository currently supports the latest stable release.

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

If you discover a security issue, contact the repository owner privately with:

- A clear description of the issue
- Steps to reproduce
- Potential impact
- Suggested mitigation, if available

Please allow reasonable time for investigation and remediation before public disclosure.

## Security Practices

This project includes security-focused controls such as:

- JWT-based authentication
- Argon2 password hashing
- Per-user data ownership boundaries
- Rate limiting
- Request size limits
- MIME validation
- Security headers
- CORS and trusted-host restrictions
- Structured logging and request tracing
- Automated tests and CI checks

Security issues are treated as high-priority defects.
